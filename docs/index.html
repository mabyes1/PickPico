少量穩定入口，能力需要時再長出來。

server_infocapability_searchcapability_statuscommand_run

PickPico 不把所有手機工具一次塞給模型。Agent 先搜尋需要的能力，取得可用狀態、風險與 schema，再用同一個執行入口呼叫。

為什麼：降低工具列表與 context 負擔，也讓手機新增或更新能力時，不必依賴客戶端重新載入一整套固定 MCP schema。

Human Help 不是失敗出口。它是 Agent 把「人類 3 秒能完成的事」納入工作流的方法。

1
Agent 用相機看 ESP32需要的資訊不在正面。
2
發出 Human Help請使用者把板子翻到背面。
3
人完成實體動作透過求助頁回覆；若系統要求解鎖，先由使用者完成。
4
Agent 再拍一次人類回覆回到求助呼叫，Agent 再呼叫相機繼續工作。
TRUST

不用 Root，不用 ADB，不繞過 Android 安全邊界。

01

能力開放

相機、麥克風、位置等由 Android 權限管理。

02

Hyper Mode

畫面操作、通知存取與螢幕擷取需要開啟此模式及對應系統授權。

03

OS Hard Boundary

PIN、指紋、Wallet 簽署等仍由 Android 或目標 App 處理。

04

Sandbox

檔案與程式在 PickPico App 私有空間內運作。

Can do ≠ May do. Agent 找得到能力，不代表能無條件執行。
