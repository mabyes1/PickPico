## 產品方向

使用者打開時能立即回答：現在誰在操作、做什麼、我能怎麼接手、最後完成了什麼。技術連線資訊留在診斷頁；日常首頁使用生活語言。

## 已觀察到的問題

- 球內 OPEN ACTIVITY 是高對比主按鈕，回到 ChatGPT 是次要文字，與目前主要用途不符。
- 球面板底下的桌面圖示仍可見，資訊較雜；正文及動作多為 11sp，中英混合。
- 返回 App 設定頁用預設 ListView，沒有搜尋、App 圖示、選取勾選、明確返回列；套件名稱直接占據每列。尚未套用主題或 SystemBarInsets。
- 球內主按鈕 40dp、設定列 44dp；需將實際觸控區至少提升為 48dp。
- 語意點擊在球的動態狀態下曾被 STALE_OBSERVATION 擋下；需重現並分離無關狀態刷新與目標有效性，不移除真正的過期保護。
- 通知清理已有私有 JSON 紀錄，但欠缺讓使用者直接閱讀的管家摘要頁。
- 持續亮屏依賴未結束任務，Agent 消失時可能一直保持；需要本機可控的停止流程。

## P0：今晚優先交付

### 1. 重整球內層級

頂部：Agent 名稱與一行目前工作；下一行簡短狀態（處理中／等你協助／已完成／連線中斷）。

主操作：回到 ChatGPT（使用者預設時標示「預設 App」，任務連結時標示「此次任務」）。需人協助時以「處理協助」優先。

次操作：查看進度、停止操作。返回設定放在較小的設定入口，但保留 48dp 觸控範圍。

空閒時縮成簡單返回捷徑；任務結束顯示結果，不持續佔用大面板。保持單擊開面板，直接返回可以作為可選點擊行為，避免修改既有手勢造成誤觸。

### 2. 返回 App 選擇器

沿用 PickPico 主題；上方返回列、搜尋框、已選 App 區塊；清單用 App 圖示＋名稱＋勾選，套件名稱放詳細資訊。點選立即儲存並有明確回饋。清除預設是次要操作。

### 3. 本機停止與控制權

停止必須先拒絕後續操作，再取消可中斷工作、終止任務並釋放亮屏。已送出的不可中斷動作需顯示實際狀態。停止不等於抹除操作紀錄，也不默認關閉整個連線服務。

Agent 長時間無活動時可顯示「仍保持亮屏」與停止入口；不因任意閒置計時器違反使用者的持續亮屏硬性規定。

### 4. 日常首頁與通知摘要

首頁資訊順序：目前工作 → 等你處理 → 最近結果。連線細節與能力清單降為次層。

清理通知：先保存快照 → 批次清除 → 驗證 → 顯示摘要。摘要分需要處理、一般資訊、已清理；同來源重複項目合併。顯示實際清除/保留數與系統不可清除項目。失敗不能顯示完成。

提供清理歷史與保留期限選擇。保留通知文字不等於能恢復原通知或其 action；不提供虛假的「復原通知」。本階段不自動刪除既有摘要紀錄。

## P1：下一輪

- 連線健康卡：最後在線、已知觀察、確定原因與推測分開、下一個可執行的恢復入口。不能保證被強制停止後可自行喚醒。
- 返回失敗修復：目標 App 已移除、連結打不開時提供改選 App 或重新設定，保留原設定直到使用者修改。
- 任務收據：本次改了什麼、成功與失敗、仍需你處理的項目；手機端可回看。
- 使用者接手：明確暫停／繼續控制協定，避免人和 Agent 同時點擊；需和實際執行端整合，不能只有 UI。
- 分享給 Agent：從 Android 分享內容帶回已設定的入口；需先確認接收 App 支援的內容類型，不能假設可直接送進特定聊天室。

## P2：獨立規劃

- 桌面整理先預覽頁面／資料夾提案，再套用並記錄前後差異；各 Launcher 支援程度需實測。
- 影片觀察使用有時間戳的有界影格批次與變化取樣，顯示觀察中且可停止；先定義時間上限、取樣密度及輸出摘要，再做長時間連續擷取。

## 視覺規格與驗收

- 沿用使用者主題色；面板以穩定深淺底提高可讀性，裝飾集中在 Pico 球。
- 主動作只保留一個高對比焦點；狀態不可只靠顏色。
- 正文初稿 14–16sp、主動作 15–16sp；支援系統字級放大，文字不得裁切。
- 所有點擊區至少 48dp；對照 Android 官方無障礙指南：https://developer.android.com/guide/topics/ui/accessibility/apps
- 驗收深／淺主題、繁體中文長標題、200% 字級、鍵盤、安全區、橫向窄螢幕、TalkBack。
- 功能驗收：預設返回、任務明確返回、未安裝目標、無設定、停止後拒絕後續動作、最後任務結束釋放亮屏、清理成功與部分失敗、斷線重連。

## 建議執行順序

先做三個可點擊畫面（球面板、返回選擇器、通知摘要），確認資訊主次與主題效果。優先落地球＋選擇器＋停止流程，再接摘要與健康頁。不在同一晚同時重寫 Launcher 操作和影片觀察。
