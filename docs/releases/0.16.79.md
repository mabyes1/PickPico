# PickPico 0.16.79

## 佈景選色修正

- 從遠端 main 的 `d017222`（0.16.78）接續修改。
- 移除黑白捷徑與固定色票。Color A／Color B 改用可點選、拖曳的連續調色盤，搭配彩虹色相條與六位色碼輸入。
- 原本固定色票逐一設定滑桿時，共用 HSV 陣列會被滑桿事件覆寫，導致後續飽和度、亮度取到錯誤數值。新版統一同步調色盤、色相和色碼，避免互相覆寫。
- 按 Apply 直接保存所選顏色，並同步更新背景、玻璃、文字與 PICO 預覽；取消保留原色，無效色碼會提示修正。
- 單色模式隱藏不參與顯示的 Color B；開啟漸層後恢復，先前選色仍保留。
- 原版／火焰版 PICO 切換及既有玻璃效果設定保留。

## 驗證

- Android 測試 195 項通過，debug APK 0.16.79（116）建置成功。
- 新增 Android 介面測試：兩個顏色按鈕開啟調色盤、Apply 更新當前與保存的佈景、重開頁面保持顏色、取消保留原色、無效輸入不關閉視窗。
- 新增調色盤測試：觸控取色、色碼與色相同步、黑白端點，以及無效輸入檢查。
- 手機 PickPico 連線連續回傳 Internal error，ADB 沒有可用裝置。本版尚未送到手機，也尚未完成真機操作驗證；沒有發布公開 OTA。
