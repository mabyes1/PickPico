## 變更

- 18 個常用能力直接提供完整參數；保留 12 個管理／探索入口，共 30 個工具。其餘 38 個列在短索引，全部 60 個 ID 為固定合法選項。
- `capability_status` 提供精確規格、版本與呼叫提示。搜尋保留讀寫意圖，預設最多 3 筆，精確 ID 只回該能力。
- 共用參數驗證在執行與本機核准前拒絕必填、型別、範圍及未知欄位錯誤；保留模型名稱要求與原本核准政策。
- 直接 UI 動作要求最新 `observationId`，每次觀察只供一個動作；過期、畫面已變、同名目標不明確或 path 無效時拒絕操作。舊動態 UI 呼叫保留可選 observationId 的相容行為。
- UI 預設精簡元件，支援搜尋與分頁。任務／命令歷史預設摘要，以 ID 取得完整內容。
- 檔案預設每次約 8 KB，保留 UTF-8 字元邊界，用 offset 與檔案 SHA-256 接續，檔案改變時拒絕混接。程序輸出提供 stdout／stderr 獨立游標，預設各 8,192 個 UTF-16 字元，保留表情符號邊界。
- `human_help` 預設立即回傳 requestId；`human_help_status` 可等待最多 25 秒。舊動態求助仍預設等待，本機核准流程不變。
- 操作失敗、等人、仍在執行及結果不明分開回報；查詢過去失敗紀錄仍可成功。結果不明時提示先確認現況，禁止把重試當成安全預設。
- 純查詢工具提供正確行為提示，混合執行入口不宣告只讀。
