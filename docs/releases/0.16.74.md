## 主要變更

- 修復 Relay 換線後舊排隊請求仍執行，包含本地 HTTP 分派與核准返回後的有效性檢查。
- 修復程序 stdin 寫入／flush／close 阻塞避開期限的問題；背景服務保留成功完成輸入後的常駐語意。
- 模型型號 `agent` 在 task_create、command_run 及直接裝置工具必填，並傳入目前命令、任務、歷史與求助 UI。
- 停止鈴聲只取消自己的排程，不再清空共用 Handler。
- 統一命令執行失敗旗標、歷史與 Pulse 狀態。
- 一般 workspace 覆寫採暫存檔原子替換；追加保留串流語意。
- 截圖逾時或中斷後晚到的 HardwareBuffer 會被釋放。

模型名稱仍為呼叫者自報。客戶端需重新取得工具結構；未帶 agent 的舊操作會在執行前被拒絕。
執行環境未提供模型型號時，明填 `unknown (model not exposed)`，不可捏造版本。
