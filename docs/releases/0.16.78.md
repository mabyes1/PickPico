# PickPico 0.16.78

## PICO 球外觀切換

- 從最新遠端 `main` 的 `e4676a6`（0.16.77）接續修改。
- 設定 → Appearance → PICO ORB 可選擇 Original（原版流光球）或 Flame（火焰球），旁邊提供即時預覽。
- 選擇會保存，主畫面與浮動球一起套用；既有使用者預設維持原版，隨時可切回。
- 原版 `pulse-orb.agsl` 完整保留。火焰採用確認過的由中心向外流動效果，顏色跟隨佈景主色、副色及漸層開關。
- 火焰需 Android 13 以上；裝置無法載入時保留原版。原有狀態提示、心跳與完成波紋繼續使用。
- HTML 預覽與繪圖程式保存在 `docs/prototypes/pico-frenzy/`，方便後續比較調整。
