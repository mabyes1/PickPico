# PickPico 0.16.77

## 畫面操作備援

- 有可用的無障礙元件時，繼續使用元件定位。
- `ui.action` 可使用最新截圖的像素座標點擊或長按。
- `ui.scroll` 可使用最新截圖的起點與終點執行滑動。
- Android 13 以上可在畫面欄位已聚焦後，透過輸入連線完成無元件文字輸入。
- 最新截圖的操作識別值只能使用一次，逾時、重用、前景改變或座標超出畫面都會在操作前拒絕。
- 操作指南改為「有元件用元件；沒有元件看截圖操作」，每次操作後必須重新觀察結果。
