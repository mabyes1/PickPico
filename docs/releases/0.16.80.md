# PickPico 0.16.80

## Human Help 前景顯示

- 一般畫面下，依既有 Hyper Mode／背景啟動權限直接啟動求助頁；不再依賴全螢幕通知是否被 Android 展開。
- 鎖定時保存請求，接收解鎖事件並補顯示。等待解鎖不消耗回覆期限；不主動要求解除安全鎖。
- 回覆期限在首次確認頁面顯示後重新起算。`deliveryStatus` 為 `received`、`waiting_unlock`、`launching`、`displayed` 或 `blocked`，並提供 `deliveryReason`。原本的請求 `status` 與 `completed` 回覆契約不變。
- `displayed` 只代表已解鎖且頁面取得前景焦點，不代表使用者已閱讀。`startActivity` 沒有拋錯不算已顯示。
- 未取得顯示確認時最多嘗試三次；權限恢復或再次解鎖可重新嘗試。已顯示過的請求不會在使用者離開後反覆搶回前景。
- 系統拒絕啟動時保留通知，回報未確認／缺少權限。未顯示而逾時的請求標記 `delivery_timeout`，不誤報人類無回應。
- 多筆請求依建立時間處理，已有求助頁等待回覆時不互相覆蓋。既有預覽與舊版未處理請求不自動重播。
