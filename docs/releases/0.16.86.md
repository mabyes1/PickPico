# PickPico 0.16.86 (124)

Promotes the user-approved 0.16.86-dev UI and phone-butler changes to the stable OTA channel. The higher version code allows upgrading from development build 123.

## Changes

- Compact Pico panel uses the app's shared theme background and card surface. English UI, adjustable text size, explicit close control, and corrected orb/outside-touch toggle handling.
- Return shortcut displays the selected app's installed icon. Searchable themed app picker shows app names, icons and selection without package identifiers. Explicit task return destinations take precedence over the saved default.
- Non-terminal agent tasks hold the screen awake until completion, failure or cancellation. The last task releases the hold without changing the system display timeout.
- Batch notification dismissal saves a private snapshot before clearing, verifies remaining notifications and supports replay-safe request IDs.
- Connection diagnostics expose observed network/power state and historical process exits without claiming an unverified disconnection cause. Service recreation retains the task runtime within the same service instance.
- Includes the previously developed Human Help foreground-delivery changes after stable 0.16.79.
