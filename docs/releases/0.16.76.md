# PickPico 0.16.76（113）

## 修正

- 移除對外 `agent` 規格的 `pattern`，保留必填字串、1–160 字長度。手機端仍拒絕漏填、空白、不可見字元及過長名稱，模型顯示與核准政策不變。
- 完整能力清單與預設搜尋不再排除暫時不可用的能力；以 `available=false`、原因和設定需求呈現。只有明確指定 `availableOnly=true` 才篩選。
- 執行已知但不可用的能力時，沿用共用參數驗證及可用狀態檢查，回傳 `CAPABILITY_UNAVAILABLE`，不執行操作。

## 原因與界線

LUNA 的 2026-09-12 16:40 測試在 OpenAI 連接器驗證階段拒絕 `unknown (model not exposed)`、一般模型名稱及其他探測值。原始錯誤為 `agent [pattern]: String does not match pattern`，尚未送到手機。

原公開規格的 `\S` 本身是合法的非空白匹配式；目前沒有證據斷言是整串比對、轉義或哪一個 OpenAI 內部模組造成。移除跨連接器容易產生差異的重複檢查，保留手機端既有嚴格檢查，作為相容性修正。此處不是取消工作區管理政策或手機本機核准。

先前完整清單使用 `isCommandExposed()`，Android 實作以「當下可用」決定是否列出，因而可能從 60 項縮成 58 項。原單元測試把全部能力模擬為可用，漏掉此情境；本版補上兩項不可用時的清單／搜尋／拒絕執行測試。沒有將實機缺少的兩项擅自指認為特定能力。
