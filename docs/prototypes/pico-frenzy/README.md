# PICO flame appearance preview

Open `index.html` in a browser. No server or network connection is required;
keep `fluid-orb.js` beside the HTML file.

The accepted flame uses a small dark core, white-hot inner fire, translucent
outer fire, and continuous motion away from the centre. Primary and secondary
colours follow the theme; disabling the gradient uses the primary colour only.
The Original button provides a comparison with the existing PICO sphere.

The Android implementation lives in `app/src/main/assets/flame-orb.agsl`.
The original `pulse-orb.agsl` remains intact. Both are selectable in
Settings → Appearance → PICO ORB. Android uses the accepted default flame
shape; the extra browser sliders are design controls, not App settings.

Screenshots, reference contact sheets, and intermediate HTML drafts are local
review material and are excluded from Git.
