# 手機操作指南

0.16.48 起，`capability_search` 除了原有的工具結果，也回傳 `guides` 摘要。
AI 依任務選擇指南，透過 `command_run` 讀取完整內容：

```json
{"commandId":"guide.get","arguments":{"guideId":"app.operate"}}
```

目前提供三份指南：

- `app.operate`：找到 App、開啟、確認畫面、選擇操作方式、驗證結果。
- `ui.find_and_fill`：同名元件、捲動區域、輸入、鍵盤遮擋、搜尋與提交。
- `ui.recover`：權限不足、畫面不可讀、黑屏、無效點擊與人工協助後接續。

每個情境包含「何時適用、採取什麼動作、如何驗證」。這些是依情況使用的建議，讀取指南不會執行手機操作，也不改變使用者授權。

搜尋只載入摘要，讀取時才取得完整內容與相關工具的當下狀態。工具參數仍以能力搜尋結果為準，避免指南另外維護一份過期參數。搜尋的 category、group、availableOnly、limit 保持原有工具篩選語意；指南是另外附上的任務建議，不代表相關能力都可用。

## 日常測試重點

用平常的自然語言交代任務，不必手動指定指南。觀察 AI 是否主動讀取指南，以及：

- 開啟 App 後是否確認真的到達正確頁面。
- 換頁或捲動後是否重新觀察，避免用舊元件。
- 連續兩次無進展是否換方法，而非反覆盲點。
- 輸入與提交後是否確認結果，逾時時是否避免重複提交。
- 求助後是否重新觀察並接續；是否尊重拒絕或取消。

記錄任務、版本、卡住畫面、最後幾次工具呼叫與實際結果。比較成功率、無效重試與誤報完成，不能單靠指南已載入就認定變聰明。

指南由 `OperationGuides.java` 維護，內容更動時增加 revision。先把可重用的失敗經驗加入判斷分支；只有實測顯示底層能力不足時才新增操作 API。
